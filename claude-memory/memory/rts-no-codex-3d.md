The creator's rule for the RTS (relayed by the Manager, 2026-11-21): never rely on Codex for 3D models or animation. Use CC0 clips and models, or make them ourselves with the rig tools, bakes and code (skin.js, foot-motions.mjs, make-clips.mjs). Codex does 2D only (icons, paintings).

**Why:** Codex's earlier 3D work (prototype bodies, the asked-for clip briefs) didn't serve the game; the clips that work are CC0 or made in code here.

**How to apply:** when a unit needs a new clip, prop or skeleton, source a CC0 asset (Quaternius, Kenney, the asset scout's finds in assets/scout) or build it in the bake; never write a Codex brief for it or wait on one. See [[rts-art-preferences]], [[rts-project]].
