When two notes conflict and the user picks one, delete the other. Don't add a new line saying which one won ("the sky is blue, not purple"). Just leave the winning note.

Record incidental feedback at the size the user gave it. A comment on one batch or one image is about that batch or image, not a rule for every future one. The user's example: a remark that the red characters shouldn't all wear red sashes became "no red sashes ever".

**Why:** on 2026-11-08 the user said correction notes and hardened rules pile up and pull the project away from their vision. Keeping only the current answer leaves room to change their mind later.

**How to apply:** this covers my memory and the project's notes and skills. When writing a note, separate what the user decided from what I observed or proposed, and don't word my observations as prohibitions. When a decision replaces an older one, edit or remove the old text rather than appending history. See [[breachline-project]].
