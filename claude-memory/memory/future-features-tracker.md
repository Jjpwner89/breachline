Parked card features, keywords and gameplay ideas (Kicker, Flash, Cycling, Morph, shrines, traps, and so on) are kept in breachline/FUTURE_FEATURES.md. Only card, keyword and gameplay ideas go there, not modes or tools.

**Why:** the creator wants them easy to find whenever the card pool expands, but decides each one (2026-11-12).

**How to apply:** check the list when designing new cards or decks, and suggest an idea when it fits. Never build one without the creator's approval. Delete an entry once it's built. Related: [[breachline-project]], [[quick-balance-check]].
