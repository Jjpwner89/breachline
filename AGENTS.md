# Breachline project guidance

For Breachline art briefs, image generation or art review, read and follow:
- [.claude/skills/art-direction/BRIEF_WORKFLOW.md](.claude/skills/art-direction/BRIEF_WORKFLOW.md) for the shared brief-writing and art-agent process.
- [.claude/skills/art-direction/SKILL.md](.claude/skills/art-direction/SKILL.md) for current art direction.
- [breachline/SETTING.md](breachline/SETTING.md) and the workflow's relevant card/reference sources for current world facts and approved designs.

“Make art briefs” uses the compact format and brief-writer responsibilities in that workflow. “Use the latest briefs” uses its art-agent intake and generation responsibilities. Read the current files each batch; do not reuse an older brief's style boilerplate. These instructions apply only to Breachline art work; they do not alter unrelated projects.
